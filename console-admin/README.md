# Admin console

Internal operations and support tooling.

Roles: Support, Ops, Finance, Reviewer, Admin. SSO with mandatory 2FA. Least privilege.

Access to decrypted birth data requires a recorded justification and is audit-logged. Every
administrative action is written to the append-only audit log with actor and reason.

Capabilities: order inspection and intervention, astrologer management and quality scoring,
refunds and credit notes, content and rule-set management, support ticket linking.
